# 等保拓扑 · 网络拓扑图绘制平台

面向网络安全等级保护测评场景的**纯前端、离线可用**拓扑绘制工具。无需安装、无需后端、无需构建，双击 `index.html` 即可使用。

项目自带 137 个按「5 大类 → 23 个二级子类」组织的矢量资产图标、4 套等保典型拓扑模板，以及资产清单、报告版式导出、合规自检等测评专用能力。

## 主要功能

- **资产图标库**：网络设备、安全防护设备、计算与终端、数据与应用、区域与标注共 137 个自绘 SVG 图标；支持中文 / 拼音 / 英文 / 分类名搜索、分组折叠、平铺切换、自定义 SVG 图标导入（白名单净化）。
- **画布**：拖拽添加、拖动 / 框选 / 多选、20px 网格吸附与智能对齐参考线、滚轮缩放、空格或中键平移、迷你地图、双击就地改名；安全区域框是真正的容器，可整体移动、自动归属、锁定。
- **连线**：可连资产或区域框，支持正交折线（自动避障）/ 直线 / 曲线、虚线、颜色、线宽与标注；选中后拖动两端圆点可改接端点。**默认不带箭头**，需要表示数据流向时可单独开启或批量切换。
- **资产属性**：精简为 6 个填写字段（资产名称、IP / 地址、设备型号、系统 / 版本、所属安全区域、备注说明）+ 资产图标选择；资产清单可勾选批量设置，导出 CSV。
- **报告交付**：A4 横向成品图，含标题栏（图号、密级、编制人、单位、日期）、按图中实际资产自动生成的图例与页脚；可导出 PNG / SVG / 工程 JSON / CSV / 文本报告。
- **合规自检**：依据 GB/T 22239-2019 的三级 / 二级检查项，三个视图——链路感知自检结果（设备未接入链路或未位于边界链路时降级为「待人工核实」）、控制点-资产证据矩阵、跨区边界与外部到数据资产的可达路径分析。
- **工程管理**：多页工程、操作历史回退、整改前基线快照与前后差异对比、只读评审模式、工程导入导出与自动本地保存。

## 快速开始

### 方式一：本地离线使用

直接双击 `index.html`（Chrome / Edge 推荐）。所有数据保存在浏览器 `localStorage`，不上传任何服务器。

### 方式二：GitHub Pages

本仓库是零依赖静态站点，在仓库设置中把 Pages 源指向 `main` 分支根目录即可，无需构建步骤。

> **重要：本地数据与网页版不互通。** `localStorage` 按 origin 隔离，`file://` 下绘制的图在 `https://<user>.github.io/<repo>/` 中看不到，反之亦然。跨环境迁移请用「导出 → 保存工程 JSON」再「导入」。

首次打开会显示起点选择：等保三级典型拓扑 / 等保二级通用拓扑 / 空白画布。

## 导出说明

内置预览面板或 iframe 可能拦截浏览器的自动下载。每次导出都会弹出**导出结果面板**，显示文件名与内容预览，并提供四种兜底方式：

- 保存到本地…（系统保存对话框，Chrome / Edge 支持）
- 点击下载副本（可见的真实下载链接）
- 复制全部内容（可直接粘贴进 Excel）
- 在新窗口打开

下载正常时可勾选「不再自动弹出」，之后用「导出 → 查看上次导出结果」随时取回。

## 目录结构

```
index.html                  页面入口
assets/css/style.css        界面样式
assets/js/icons.js          137 个矢量图标与分类索引
assets/js/schema.js         工程模型、字段定义、校验、版本迁移、差异对比
assets/js/templates.js      4 套拓扑模板与合规检查规则
assets/js/compliance.js     链路感知自检、证据矩阵、边界与路径分析
assets/js/report.js         A4 报告版式、图例、文本报告
assets/js/app.js            画布引擎与界面逻辑
tests/verify.js             回归测试（Node 内置模块，无需安装依赖）
```

脚本按 `icons → schema → templates → compliance → report → app` 顺序加载，全部为普通 `<script>`，不使用 ES module，因此 `file://` 下也能直接运行。

## 开发与测试

```bash
node tests/verify.js          # 或 npm test
node tests/check-release.js   # 或 npm run check:release
```

- `verify.js`：轻量 DOM 桩在 Node 中真实执行全部 JS，覆盖数据模型、画布交互、报告导出、合规语义、工程管理等 41 项路径。
- `check-release.js`：发布前自检，扫描本地绝对路径、个人信息、非文档/非私有 IP、导出物，并核对 `.gitignore` 关键规则与基础文件。

两者都只用 Node 内置模块，**不需要浏览器、不需要 `npm install`**。CI 通过 GitHub Actions 自动运行。提交前建议至少跑一次 `npm run check:release`。

## 浏览器支持

| 浏览器 | 支持情况 |
|---|---|
| Chrome / Edge | 完整支持（含系统保存对话框） |
| Firefox / Safari | 主要绘图与导出功能可用；「保存到本地…」按钮自动隐藏，请用其余兜底方式 |

依赖 `Pointer Events`、`SVG innerHTML`、`URL.createObjectURL` 等现代浏览器能力，不支持 IE。

## 隐私与保密

- 工具**不联网、不上传数据**，工程数据仅存于本机浏览器 `localStorage`。
- 仓库内模板使用的是 RFC 1918 私有示例地址与 `example.com` 域名；`内部资料` 为密级输入框的默认占位值，不代表任何真实密级。
- **不要把含真实 IP、设备型号、资产台账的工程 JSON、CSV 清单、自检报告或报告图片提交进仓库**。`.gitignore` 已忽略根目录 JSON、常见导出物与 `exports/` 目录；提交前仍请执行 `git status` 与 `git diff --cached` 复核。
- 导出文件建议统一放入 `exports/` 目录，并按所在单位保密要求自行审核后再外发。
