使用说明

一、绘制拓扑

添加资产：左侧图标库按「5 大类 → 23 个二级子类」分组，共 137 种资产，支持设备名 / 拼音 / 英文 / 分类名搜索、分组折叠与平铺切换。拖拽到画布，或单击图标后点击画布放置。

连线：点「连线」后依次点击两个对象——既可以是资产，也可以直接点区域框内部空白处连到整个区域（表示边界链路），松开鼠标在画布空白处会自动生成一个可命名的「连接点」。鼠标悬停对象即出现浅色端口，不必切换工具或先选中即可拖出新连线；拖拽时按当前线型实时预览并吸附目标端点。选中连线可拖动两端圆点改接端点，正交折线还可拖动紫色控制点手动调整拐点，属性面板「重置走线」恢复自动避障。右侧属性面板可改线型、虚线、箭头、颜色与标注，并支持把当前箭头 / 线型一键应用到全部连线、交换起止方向。新建与模板预置连线默认不带箭头，需要数据流向时用工具栏「默认箭头」开启（仅影响之后新建的连线），或选中对象后右键批量显示 / 隐藏相关连线箭头。

安全区域：区域框是真正的容器。拖动标签或边框会连框带设备一起移动；新资产落入区域自动归属；拖入 / 拖出区域、区域改名、打包和批量设置都会同步更新资产的「所属安全区域」字段，手工填写该字段时若与画布区域同名会自动建立归属关系。导出的 PNG / SVG 与报告版式会完整保留区域名称。可锁定区域防止误拖。标注更灵活：右侧面板可把区域名放到 9 个位置（九宫格）、支持回车换行写多行说明、单独调字号与文字颜色、选择虚线 / 实线 / 点线 / 无边框、调整填充深浅、显示 / 隐藏资产计数。也可按 R 在画布上拖出矩形直接画区域，或框选若干资产后右键「将选中资产打包为区域」。区域嵌套时资产归属最内层框；手工填写且无同名区域框的区域名会作为自由文本保留。

连接点：按 A（或工具栏「连接点」）在空白处点击即可放置一个可命名的小圆点，用来表示未画出的系统、云、互联网入口或注释锚点；它本身就是合法的链路端点，连线可直接连上它。

二、常用操作

资产库图标可拖到画布，也可点选后在画布落点；Ctrl / Shift 点图标进入连续放置，连续落下同类设备，Esc / V 退出。双击资产 / 连线 / 区域标签可就地改名，文本标注节点可用 Shift+Enter 换行；画布内悬停资产可看到名称 / IP / 所属区域；右下角迷你地图可点击跳转；滚轮缩放、空格 / 中键平移、Shift 多选、空白处框选、选中对象四边圆点可直接拉线、八向手柄自由改尺寸。

快捷键：Ctrl+Z/Y 撤销重做 · Ctrl+C/V 复制粘贴 · Ctrl+D 原地复制 · Ctrl+A 全选 · Delete 删除 · L 连线 · H 手型 · R 画区域 · A 连接点 · V 选择 · 0 适应 · 方向键微调 · Esc 取消（优先关闭弹窗 / 菜单，不清空选中）。

三、报告交付

资产清单：按 6 个资产字段汇总（名称、IP、型号、系统版本、安全区域、备注），可勾选后批量设置安全区域、设备型号、系统版本、备注，导出 CSV 直接用于资产调查表。

导出说明：每次导出会弹出「导出结果」面板，显示文件名与内容预览，并提供保存到本地、下载副本、复制全部内容、新窗口打开四种兜底方式；内置预览面板可能拦截自动下载，此时用这四种方式即可取回文件。下载正常后可勾选「不再自动弹出」，之后随时用「导出 → 查看上次导出结果」打开。导出的 SVG / PNG / 报告版式图片内嵌完整工程数据，用「导入」选中即可还原为可编辑拓扑；普通截图会明确拒绝且不影响当前画布。

报告版式：工具栏「版式」可设置图号、密级、编制人、单位、日期；导出「报告版式 PNG/SVG」会生成 A4 横向、带标题栏、图例与页脚的成品图，可直接插入测评报告。

四、工程管理

画布顶部可建多个页面；左侧「工程与历史」可保存整改前基线、输出前后差异清单、回退到任意历史步骤、导入自定义 SVG 图标；「只读评审」开关用于给专家看图时防误改。工程自动存本地，可导出 JSON 备份与迁移，也可导入本平台导出的 SVG / PNG 图片继续编辑。左侧搜索框旁的「资产库 ⇄ / 画布内 ⇄」可切换搜索范围：画布模式按名称 / IP / 区域等查找已放置资产，回车循环定位。
